# Student Career Tracker

A full-stack web application that helps students track their skills, monitor career readiness, identify skill gaps, prepare for interviews, and improve resume readiness.

## Features

- Student Registration
- Student Profile
- Skills Tracker
- Career Dashboard
- Required Skills
- Recommended Learning
- Skill Gap Analysis
- Placement Readiness
- Interview Preparation
- Resume Readiness

## Technologies Used

### Frontend

- HTML5
- CSS3
- JavaScript

### Backend

- Node.js
- Express.js
- REST API
- CORS
- dotenv

### Database

- PostgreSQL

### Tools

- VS Code
- Git
- GitHub
- PowerShell
